## 一、模型结构（严格对应 Wang 2022 §3.1–3.4 与你论文 Eq.20–23）

| 模块 | 公式 | Wang 编号 | 你论文编号 |
|---|---|---|---|
| 气候模块 | CO2 脉冲 → 边际增温 ΔT(τ)（CMIP5+碳循环；本复现用 Joos2013 碳循环 + FaIR 二箱热响应，Ricke 2018 同源） | §3.1 | Eq.20 climate |
| 损害模块 | DJO：`G_t = G_{t-1}[1 + α_t + δ·(T_t − T_0)]` | Eq.1 | Eq.21 |
| 折现模块 | Ramsey：`γ = ρ + η·g`，ρ=0.692%, η=1.07 | Eq.2 | Eq.22 |
| SCC | `SCC(t) = −(GC(t)/(1+GR)·(1+GR+WE) − GC(t))·P(t)`，WE=δ·(T_t−T_0) | Eq.3 | Eq.20 |

化简：`SCC(t) = −δ·ΔT(t)·GC(t−1)·P(t)`。
某排放年 t0 的 SCC = 该年排 1 tCO₂ 在未来各年造成的边际损害按 Ramsey 折现率折回 t0 求和（算到 2100）：

```
SCC_{i,t0} = Σ_{τ=0}^{2100−t0}  [ −δ_i · f_i · ΔT(τ) · GC_{i,t0+τ−1} · P_{i,t0+τ} ] / (1+γ_i)^τ
全国 SCC_{t0} = Σ_i SCC_{i,t0}
```
